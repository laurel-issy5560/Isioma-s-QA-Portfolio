
# Isioma's QA Portfolio

Welcome to my QA Portfolio! This repository showcases my practical work in Quality Assurance, including API testing, automated reports, and test case documentation.

---

 Projects Included

 1. API Testing with Postman & Newman
- **Postman Collections**: Organized API tests for different projects.
- **Environment Files**: Contains variables used in Postman tests.
- **Newman HTML Reports**: Automated test run reports using Newman + `htmlextra` reporter.

**Files:**
- `JSONPLACE HOLDER.postman_collection.json`
- `JSP ENV.postman_environment.json`
- `report.html`

---

### 2. Manual Test Cases
Excel test cases documenting functional testing for different web applications.

**Projects:**
- **QA TestCraft Demo Website** → `Test-Cases/QA TestCraft Test Case.xlsx`
- **Gradific Demo Website** → `Test-Cases/Gradific Testcase.xlsx`
- **SauceDemo** → `Test-Cases/SauceDemo Testcase.xlsx`

These test cases include:
- Test steps  
- Expected results  
- Actual results  
- Status (Pass/Fail)

---

##  How to Use
1. Clone this repository:  
git clone https://github.com/laurel-issy5560/Isioma-s-QA-Portfolio.git

2. Open the Postman collections in Postman to run tests.
3. View Newman HTML reports in a browser.
4. Open Excel test cases to review manual testing steps and results.
