# QA Portfolio – API Testing with Postman & Newman

This project shows my work in testing APIs using Postman and running the tests with Newman.

 Project Description:

I created API test cases in Postman and used Newman to run them from the command line.  
I also generated an HTML report to show the test results.

 Files:

- JSONPLACE HOLDER.postman_collection.json – Postman collection  
- JSP ENV.postman_environment.json – Environment variables  
- report.html – Test report generated by Newman  

Tools Used:

- Postman  
- Newman  
- GitHub
  
 How to Run:
   
1. Install Newman:
npm install -g newman newman-reporter-htmlextra

2. Run the tests:
newman run "JSONPLACE HOLDER.postman_collection.json" -e "JSP ENV.postman_environment.json" -r htmlextra --reporter-htmlextra-export report.html


3. Open the report.html file in your browser to view the results.
